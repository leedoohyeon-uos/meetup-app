約束 약속잡기

사용 방법

  1. 이름과 생년월일 등록
    처음 접속하면 이름과 생년월일 6자리(YYMMDD)를 입력해요. 동명이인은 생년월일로 구분되고, 이미 등록된 정보라면 그대로 불러와요.
  2. 그룹 참여 또는 약속 생성
    기존 약속방 이름과 비밀번호를 입력해 참여하거나, "약속 만들기"로 새 약속방을 만들어요.
  3. 날짜형 / 시간형 선택
    날짜만 조율할지, 날짜+30분 단위 시간까지 조율할지 약속 생성 시 정해요.
  4. 가능한 일정 입력
    클릭·드래그로 칸을 선택하면 X(불가능) → ○(가능) → △(가능하지만 비선호) 순서로 상태가 바뀌어요.
  5. 마감 후 결과 확인
    설정한 기간이 끝나면 더 이상 입력할 수 없고, 참여율이 높은 순서대로 초록~주황 그라데이션으로 결과만 보여줘요.
  6. 초대 링크 공유
    약속을 만들면 고유 링크가 발급돼요. 이 링크를 받은 사람은 이름 등록만 하면 비밀번호 확인 후 바로 입장할 수 있어요.
